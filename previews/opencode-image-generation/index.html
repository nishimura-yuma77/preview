導入ガイド · 画像生成

OpenCodeで画像生成を使うには？

今回確認したいこと：チャットから画像を作って保存するなら、どの接続方法が扱いやすいか。

既製のMCPサーバーをつなぐ方法と、画像APIを呼ぶ専用ツールを追加する方法がある。最初の一枚を試すなら、APIキーを用意できるサービスから始めるのが早い。

チャットから画像ができるまで

  1. 1. OpenCodeで依頼「背景画像を1枚作って」
  2. 2. 生成ツールが実行MCPまたは専用ツールが画像APIを呼ぶ
  3. 3. ファイルを確認PNGなどを保存し、保存先を返す

チャット内への画像表示・添付は、ファイルを生成できることとは別。利用中のクライアントで確認する。

使える候補

Gemini · Nano Banana

つなぎ方
コミュニティ製 Nano Banana MCP。READMEにOpenCode設定例と保存先指定の説明がある。
必要なもの
Gemini APIキー、利用枠、MCPの実行環境（READMEの例は uvx）。
向く用途
既製のツールで生成・参照画像を使った編集を試す。

OpenAI · GPT Image

つなぎ方
専用ツールから 公式Image API を呼ぶ。コミュニティ製MCP も候補。
必要なもの
画像APIを使えるOpenAI APIキーと課金設定。アカウントによっては組織認証も必要。
向く用途
既存のOpenAI API契約を使う。専用ツールなら、保存先や1回の生成枚数を固定しやすい。

ComfyUI · 自前運用

つなぎ方
専用ツールから ComfyUIのHTTP API へワークフローを送る。
必要なもの
ComfyUIの稼働環境とモデル。ローカル推論ではモデルに応じたGPUなどの計算資源が必要。
向く用途
設定済みの生成ワークフローを使い回す。ローカルモデルを使えば素材を手元で処理できる。

この環境で確認したこと

opencode --version は 1.19.6。opencode mcp list には設定済みサーバーがなかった。上の候補は公開資料で確認した段階で、接続や画像生成は未試行。

OpenCodeの公式MCP資料で接続機能を確認できる。現行サイトの設定例にはV2向けもあるので、実際の追加時はインストール済みの1.19.6に合わせる。

最初の一枚をどこで試す？

使えるAPIキーがあるなら、そのサービスで画像1枚をローカルに保存するところから。生成後にチャットへ添付する必要があるかは、次に検証できる。
